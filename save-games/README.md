# Community Save Games

This directory holds PlayStation 1 save containers shared for community use.
Files remain in their original DexDrive `.gme` container format.

## Collection

| File | Format | Origin |
| --- | --- | --- |
| `pro-evolution-soccer-2.22507.gme` | DexDrive (`.gme`) — Pro Evolution Soccer 2 (2 saves: `BESLES-03946PES-OPT`, `BESLES-03946PES-D2A`) | [Toukichi1 on GameFAQs](https://gamefaqs.gamespot.com/ps/582940-pro-evolution-soccer-2/saves) |

## Using a save

Convert a save to RetroArch format with JAPS1ME:

```sh
japs1me convert save-games/pro-evolution-soccer-2.22507.gme pes2.srm
```

Back up any existing `.srm` first. `convert` never overwrites an existing
output file.

## Adding saves

When contributing a save, keep its original `.gme` container and use a
descriptive filename. Include the game, region or product code when known, a
brief description, and where the save came from. Only contribute files you
created or have permission to redistribute. Do not include personal
information or credentials in save data.
